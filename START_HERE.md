## 📁 File Structure

```
src/
├── components/       # Navbar, Footer, Countdown, etc.
├── pages/           # Home, OurStory, Celebration, Gallery, Surprise
├── data/            # EDIT THESE! (weddingConfig, storyData, etc.)
├── styles/          # Design system (colors, fonts, spacing)
├── hooks/           # Custom React hooks
├── utils/           # Helper functions
├── App.jsx          # Main component
└── main.jsx         # Entry point
```

## 🎨 Customization

### Update Wedding Info
→ Edit: `src/data/weddingConfig.js`

### Add Your Story
→ Edit: `src/data/storyData.js`

### Set Event Details
→ Edit: `src/data/celebrationData.js`

### Add Photos
→ Edit: `src/data/galleryData.js`

### Write Love Letter
→ Edit: `src/data/surpriseData.js`

### Change Colors/Fonts
→ Edit: `src/styles/variables.scss`
